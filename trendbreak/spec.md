# 股票下降趋势收敛临界点自动识别系统 (TrendBreak-Detector)
## 需求与开发规格说明书 (V1.0)

---

### 1. 系统目标
基于 Python 3.9+ 及开源金融数据接口 **AkShare**，构建一套自动化形态识别工具。该工具能自动计算股票价格的几何阻力外包切线，识别震荡收敛末端、多均线纠缠并处于变盘临界状态的个股，输出候选股票池并支持可视化验证。

### 2. 形态特征的数学化与算法定义

#### 2.1 数据输入基准
* **周期**：日 K 线（前复权 `qfq`）。
* **分析窗口跨度**：回溯最近 $N$ 个交易日（默认 $N = 120 \sim 180$ 天，约半年到九个月）。

#### 2.2 几何阻力线拟合算法（Upper Resistance Line）
截图中白色压力线的本质是**“以上行波峰为顶点、覆盖绝大多数K线的凸外包切线”**。
1. **基准原点确认**：
   * 在选定窗口内，寻找全周期最高点作为原点 $P_0 = (t_0, H_{max})$。
   * **约束 1**：$P_0$ 必须处于窗口的前半段（例如距离当前交易日至少 40 个交易日以上），避免把刚刚创出新高的股票误判为长期下跌股票。
2. **候选下降切线生成**：
   * 提取 $P_0$ 之后的所有局部波峰点（Local Peaks）$P_i = (t_i, H_i)$，其中 $t_i > t_0$ 且 $H_i < H_{max}$。
   * 计算斜率 $k_i = \frac{H_i - H_{max}}{t_i - t_0}$，显式约束 $k_i < 0$（必须向下倾斜）。
3. **最佳阻力线评选规则（凸包外包过滤）**：
   * 对于候选直线 $L_i(t) = H_{max} + k_i \cdot (t - t_0)$：
     * **外包穿透容忍度**：在区间 $[t_0, T_{now}]$ 内，收盘价高于该直线的交易日天数占比必须 $\le 3\%$（允许极个别单日影线刺破，但不允许实体持续在上方）。
     * **有效触碰次数**：K 线最高价贴近该直线（相对误差 $\le 1.5\%$）的独立局部高点数量 $\ge 2$ 次。
     * **最优准则**：在满足外包条件的直线中，选取**包络面积最小（最紧绷外切线）**或**触碰次数最多**的直线方程作为最佳压制线 $L_{best}(t) = k_{best} \cdot t + b$。

#### 2.3 临界变盘点判定规则（Screening Logic）
当股票满足以下三项核心条件时触发报警：

1. **紧贴/临界突破压制线（Proximity Filter）**：
   * 计算当前最新交易日 $T_{now}$ 的阻力线理论价格：$Price_{line} = L_{best}(T_{now})$。
   * 贴近度：
     $$-2.5\% \le \frac{Close_{now} - Price_{line}}{Price_{line}} \le 1.5\%$$
   * （说明：当前价格距阻力线极近，且尚未大幅飙升逃离形态）。

2. **均线高度粘合纠缠（MA Convergence）**：
   * 计算 MA5、MA10、MA20、MA30、MA60。
   * 粘合度指标定义为：
     $$\text{Spread}_{MA} = \frac{\max(MA_5, MA_{10}, MA_{20}, MA_{30}, MA_{60}) - \min(MA_5, MA_{10}, MA_{20}, MA_{30}, MA_{60})}{MA_{20}} \times 100\%$$
   * **阈值**：$\text{Spread}_{MA} \le 3.5\%$（5根中短期均线在 $3.5\%$ 极窄幅度内缠绕）。

3. **历史跌幅充分度与企稳（Price Structure）**：
   * 累积跌幅：$\frac{H_{max} - Close_{now}}{H_{max}} \ge 20\%$。
   * 低点不创新低：近 20 个交易日最低价高于近 60 个交易日最低价（底背离或底部托平）。

4. **成交量萎缩（Volume Dry-up）**：
   * 近 5 日均量 $MAVOL5 \le 1.2 \times MAVOL60$（处于长线地量水准，尚未出现狂乱换手）。

### 3. 系统架构与模块设计

系统分为 4 个解耦模块：

```
      +-------------------------------------------------+
      |                 Main Controller                 |
      +-------------------------------------------------+
          |                    |                     |
          v                    v                     v
+------------------+  +-------------------+  +------------------+
|  1. Data Fetcher |  | 2. Geometry Engine|  |  4. Visualizer   |
| (AkShare + Cache)|  | (Trendline Fitting|  | (mplfinance 画线 |
+------------------+  |   & Peak Detect)  |  |    输出图片)     |
                      +-------------------+  +------------------+
                               |
                               v
                      +-------------------+
                      | 3. Pattern Filter |
                      | (MA/Vol/Proximity)|
                      +-------------------+
```

#### 模块 1：数据获取与缓存模块 (`data_provider.py`)
* **数据源**：`akshare.stock_zh_a_hist` 获取前复权历史日线；`akshare.stock_zh_a_spot_em` 获取股票池列表。
* **缓存机制**：本地 SQLite 或 Feather/Parquet 文件缓存，避免高频调用 AkShare 触发 IP 封锁或超时。
* **接口规范**：
  * 输入：`stock_code: str`, `start_date: str`, `end_date: str`
  * 输出：规范化 Pandas DataFrame（包含 `date, open, high, low, close, volume`）。

#### 模块 2：几何趋势线拟合引擎 (`geometry_engine.py`)
* **核心类**：`TrendlineDetector`
* **关键函数**：
  * `find_local_peaks(df, distance=10)`：基于 `scipy.signal.find_peaks` 定位关键波峰。
  * `fit_upper_resistance(df, peaks)`：执行凸外包凸度优化，输出最佳 $(k, b)$ 斜率和截距，以及该直线的穿透统计、接触点清单。

#### 模块 3：形态评估与过滤模块 (`screener.py`)
* **核心函数**：`evaluate_stock(df, trendline_params)`
* **职责**：执行第 2.3 节的所有量化条件验证，输出综合评分及各维度度量结果。

#### 模块 4：可视化渲染模块 (`visualizer.py`)
* **依赖**：`mplfinance` + `matplotlib`。
* **职责**：自动在 K 线图上叠加绘制：
  1. 拟合出的主阻力外包下倾线（白色实线）；
  2. MA5/MA10/MA20/MA30/MA60 多彩色均线；
  3. 成交量及地量均线。
* **输出**：生成与你提供的截图完全一致的视觉复原图片，存为本地 PNG。
