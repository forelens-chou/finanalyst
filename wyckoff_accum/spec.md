# 第一部分：完整开发需求文档 (PRD v2.0)

## 1. 业务背景与定位
* **业务定位**：基于经典威科夫（Wyckoff）吸筹模型，在 A 股全市场中捕捉“深度超跌 + 长期横盘磨底 + 间歇性试盘异动 + 二次/三次探底（Spring/破底翻）+ 均线极度收敛 + 地量缩量”的蓄势标的。
* **双模式分工**：
  1. **次新模式（`subnew`）**：聚焦上市 45~450 天内的次新股，追求极致弹性、无历史沉淀套牢盘、高换手爆发力（典型如海安集团、无线传媒）。
  2. **全市场模式（`all`）**：扫描上市半年以上且流通市值在 4 亿~100 亿元之间的弹性中小盘股票，排除千亿权重大象与僵尸冷门股。
* **交易核心哲学**：
  * **左侧小仓潜伏**：在探底极度缩量日尾盘以极低止损代价（$-1.5\%$）建立侦察仓；
  * **右侧放量确认**：在首板涨停或平台放量大阳突破时顺势重仓跟进。

## 2. 系统核心业务流程
```text
全市场 5300+ 标的
   │
   ▼ [截面初筛]: 剔除ST/退市/停牌/成交额不足
   ▼ [双模式分流]: 次新模式 (45~450天) vs 全市场老股模式 (不设上限)
   ▼ [周期超跌]: 较区间高位回撤 >= 38%~40%
   ▼ [弹性市值约束]: 流通市值 4亿 ~ 100亿元 (排除万科/大电力等大象)
   ▼ [平台箱体]: 60日振幅 <= 35%~38% 且 MA30走平 (排除阴跌中继)
   ▼ [试盘脉冲]: 60日内至少出现1~8次爆发性试盘针 (振幅>=4%, 放量)
   ▼ [双底/三底识别]: L2回测L1区间 (<=3.5%), 中间反弹 >=7%
   │
   ├─────────────────────────────────────────┐
   ▼ (满足今日地量小实体K线)                   ▼ (处于底部但今日非地量)
【★ 尾盘潜伏试仓买点】                       【👀 筑底观察池】
 (换手<=2~3.5%, 量<=0.5VMA20)                (供盘中动态追踪突破或等待下次回踩)
```

## 3. 功能模块详细需求
1. **数据模块（`fetch.py`）**：
   * 支持海外云服务器（Cloud Shell/VPS）毫秒级直连，不锁 IP；
   * 提供批量行情快照初筛、精准流通股本核算；
   * 提供标准无复权变异日 K 线通道与盘中实时快照接口。
2. **算法计算模块（`compute.py`）**：
   * 矢量化均线系统与 MA 离散粘合度计算；
   * 自动探测具备反弹颈线区隔的双底/三底波谷结构；
   * 检测 MACD 底背离与脉冲式试盘 K 线。
3. **离线筛选引擎（`screener.py`）**：
   * 支持 CLI 参数切换模式（`--mode subnew` 与 `--mode all`）；
   * 具备实时进度报告、阶段淘汰漏斗诊断看板；
   * 自动生成带时间戳与形态元数据的观察池文件（CSV/Parquet）。
4. **盘中监控器（`monitor.py`）**：
   * 加载最新观察池，14:45 触发尾盘潜伏预警；
   * 盘中实时捕获大阳突破/首板异动与跌破极限止损预警。
5. **回测验证器（`backtest.py`）**：
   * 独立统计“极度缩量地量潜伏”在 $T+15$ 日内的胜率、盈亏比与 MAE（最大不利下探）。

## 1. 核心数学与指标量化标准

| 指标项 | 次新股模式 (`subnew`) | 全市场老股模式 (`all`) | 计算公式 / 判定逻辑 |
| :--- | :--- | :--- | :--- |
| **上市周期天数** | $45 \le N \le 450$ | $N \ge 60$（不设上限） | $N = \text{len(KLine)}$ |
| **流通市值天花板** | 8 亿 $\sim$ 80 亿元 | 4 亿 $\sim$ 100 亿元 | $\text{FloatCap} = \text{FloatShares} \times \text{Close}$ |
| **超跌回撤幅度** | $\le -40\%$（全周期） | $\le -38\%$（近250日年线） | $\frac{\text{Close} - \max(\text{High})}{\max(\text{High})}$ |
| **箱体振幅** | $\le 38\%$ | $\le 35\%$ | $\frac{\max_{60}(\text{High}) - \min_{60}(\text{Low})}{\min_{60}(\text{Low})}$ |
| **均线粘合度** | $\le 3.2\%$ | $\le 3.5\%$ | $\frac{\max(\text{MA5..30}) - \min(\text{MA5..30})}{\text{Close}}$ |
| **MA30走平度** | $\le 5\%$ 且未大破位 | $\le 6\%$ 且未大破位 | $\left\|\frac{\text{MA30}_T - \text{MA30}_{T-20}}{\text{MA30}_{T-20}}\right\| \le \text{Threshold}$ |
| **试盘脉冲特征** | 换手 $\ge 7.0\%$，冲高 $\ge 4.5\%$ | 换手 $\ge 2.5\%$ 或 量 $\ge 2.0\text{VMA}$ | 当日全天振幅 $\ge 4.0\%$，区间出现 $1 \sim 8$ 次 |
| **双底形态回测** | 价格偏差 $\le 3.5\%$ | 价格偏差 $\le 3.5\%$ | 中间反弹高点比 L1 抬高 $\ge 7\%$ |
| **地量潜伏日特征** | 换手 $\le 3.5\%$，量 $\le 0.45\text{VMA}$ | 换手 $\le 1.8\%$，量 $\le 0.50\text{VMA}$ | 实体 $\le 1.8\%$，全天振幅 $\le 3.5\%$ |
| **硬止损线** | $\min(L_1, L_2) \times 0.985$ | $\min(L_1, L_2) \times 0.985$ | 跌破双底极限最低位 $-1.5\%$ |

* **基础快照与代码清单源**：腾讯极速行情接口 `qt.gtimg.cn`（批量 80 只/次，延迟 $<150\text{ms}$）。

# 第三部分：项目复盘总结与评估

### 1. 成功点与核心亮点
1. **轻量与高可用**：摆脱了臃肿的本地数据库，在海外公有云（Cloud Shell）低配环境下实现了 30 秒全市场扫描，架构易部署、易迁移。
2. **博弈血统高度契合**：通过精准引入“市值区间”、“均线水平斜率”与“试盘针锐度”，成功把“万科、大电力等权重死水股”与“科马材料、安乃达等爆发弹性标的”区分开来。
3. **漏斗设计透明可调**：每一道技术关卡均有明晰的淘汰统计数据，杜绝黑盒。

### 2. 存在的潜在风险与边界缺陷
1. **地量死水假底（流动性陷阱）**：部分边缘个股之所以极度缩量走平，并非主力吸筹，而是被市场彻底遗忘（僵尸股）。即便加入了 60 日均换手率底线，仍偶有漏网。
2. **大盘单边系统性风险**：在指数单边主跌浪中，技术性“双底”往往会演变为“双底再破位破底”。
3. **退市与财务暴雷盲区**：目前仅过滤了名称含 `ST` 或 `退` 的标的，尚未联动财报预告（如大幅预亏、商誉减值、大股东高比例质押）。

# 第五部分：头脑风暴——扩展不同维度的股票数据筛选方式

跳出单纯的“日线价量形态”，该底层框架可无缝接入以下几种前沿、多元的数据筛选方式：

### 1. 筹码分布与微观结构（Chip Concentration & Order Flow）
* **筹码单峰密集度（ASR / 90%筹码集中度）**：
  * *思路*：主力长期吸筹的本质是筹码从分散转移到集中。计算在当前价格上下 $10\%$ 的区间内，是否聚集了全市场 $70\%$ 以上的流通筹码。
  * *应用*：当“双底探底”刚好落在“密集单峰筹码下沿”时，胜率会成倍提升。
* **Level-2 盘口大单隐蔽吸筹比（Iceberg & Large Order Bias）**：
  * *思路*：在 14:00~15:00 期间，监控买一到买五的“隐形冰山买单”和“大单托单/主动买盘净占比”。真正的吸筹股在缩量下跌时多为散单流出，而在横盘时有持续的“主动性大单暗中点刹”。

### 2. 动量与题材关联度过滤（Sector Resonance & Relative Strength）
* **“龙头试盘，小弟跟随”板块共振**：
  * *思路*：股票极少单打独斗。当某只个股出现试盘脉冲时，扫描其所属细分行业（申万三级或概念题材板块）。
  * *应用*：若同一题材内有 $3 \sim 5$ 只超跌股票在同一周内集体出现“均线粘合 + 异动脉冲”，说明板块级游资或机构正统一步调建仓，信号可靠性极高。
* **相对强度指标（RS - Relative Strength vs. Index）**：
  * *思路*：大盘连跌 3 天创新低，而该标的在此期间不跌反涨、小幅横盘收红（逆势走强）。这种在指数下杀时的“假摔不跌”往往是 Spring 弹簧拉满的先兆。

### 3. 多周期分形共振筛选（Multi-Timeframe Fractals）
* **周线定框架，日线定买点，60分钟定执行**：
  * **周线级别**：周线 MACD 处于零轴下方初合金叉，且周线 KDJ 超卖回升，确保大方向不是无底深渊；
  * **日线级别**：符合目前设计的“箱体磨底 + 均线粘合”；
  * **60分钟级别**：二次探底时出现“60分钟级别底背离 + 早晨之星”，作为当日 14:45 精准下单的终极扳机。

### 4. 另类数据（Alternative Alpha）
* **机构调研频次激增**：在股价深跌 50% 且连续 2 个月走平期间，突然出现高频次上市公司现场调研或券商研报重新覆盖；
* **股东人数锐减度（人均持股集中度）**：结合最新一期季报，在平台箱体震荡期间，股东总户数环比下降 $>15\%$，户均持股金额逆势上升，从基本面层面佐证主力锁仓。
